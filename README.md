# SQL Sales Analysis

Analysis of a 200-row sales dataset using MySQL.

## Topics covered
- SELECT, WHERE, GROUP BY, ORDER BY
- Aggregations: SUM, AVG, COUNT
- Subqueries, CASE statements, Joins

## Files
- `sales_queries.sql`: all SQL queries


## Key Findings
1. 200 orders, total revenue 2,420,107, average order value about 12,100.
2. Furniture is the top category (714,399); Clothing is the lowest (484,259).
3. Every customer ordered once. Top customer: Lynn Garrison (47,940).
4. 81 orders (about 40%) are above the average order value.
5. High-value orders (24% of orders) bring in about 56% of revenue.
6. South leads on revenue (808,651) due to order volume; West has the highest average order value (13,938.77); North is lowest on both.
